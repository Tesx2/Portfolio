Vincent Mwangi Portfolio
=========================

Static portfolio refresh for a minimal, premium, modern visual identity.

Brand System
------------

- Primary: Dark Blue/Teal `#2F495A`
- Secondary: Bright Green `#27AE60`
- Accent: Cyan `#00C2A8`
- Background: White `#FFFFFF`
- Text: Charcoal `#222222`
- Light Background: Soft Gray `#F5F7F8`
- Headings: Montserrat Bold
- Body: Inter
- Buttons: Montserrat SemiBold

Site Structure
--------------

- Home
- About
- Portfolio
- Services
- Blog
- Contact

Portfolio categories:

- Posters
- Motion Graphics
- Brand Campaigns
- Publications
- Video Editing
- Web Projects

WordPress Migration Blueprint
-----------------------------

- CMS: WordPress
- Theme: Kadence
- Editor: Gutenberg with custom blocks where needed
- Portfolio model: custom post types for Projects, Motion Graphics, Campaigns, and Publications
- SEO: Rank Math
- Forms: Fluent Forms
- Caching: LiteSpeed Cache where supported by hosting

Project Page Content Model
--------------------------

Each project should use a story-led structure:

- Hero image or video
- Client
- Challenge
- Solution
- Process
- Final deliverables
- Gallery
- Related projects

Motion graphics projects should include:

- Video
- Project summary
- Software used
- Storyboard
- Frames
- Final video
- Credits
